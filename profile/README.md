# Comic Market Kannai

コミックマーケット準備会 館内担当の Web チームです。
スタッフ活動を支える内部向けシステムを、少人数で開発・運用しています。

> [!NOTE]
> 各リポジトリはスタッフ活動に関わるため、原則として **private** で運用しています。

## 開発について

- 新規開発は TypeScript / Python を中心に、少人数でも保守しやすい構成を心がけています
- 開発はコミックマーケット準備会の館内担当スタッフが行っています
